🎥 Cara Memasang di OBS Studio

Gunakan link di bawah ini sebagai Browser Source di OBS Studio untuk menampilkan pop-up animasi notifikasi chat secara transparan di live streaming Anda.

1

Buka OBS Studio

Pada panel Sources (Sumber) di OBS, klik tanda + (Tambah) lalu pilih Browser.

2

Tempelkan URL di atas

Beri nama sumber (misal: Alert Chat TTS), lalu paste URL di kolom URL.

3

Atur Ukuran Resolusi

Ubah ukuran menjadi: Width (Lebar): 650 dan Height (Tinggi): 220.

4

Selesai!

Pindahkan kotak alert ke posisi layar yang Anda sukai di preview OBS Studio Anda. Latar belakang sudah 100% transparan otomatis!

🔑 Cara Mendapatkan YouTube Data API v3 Key Gratis

Google menyediakan kuota gratis setiap hari (10.000 unit/hari) untuk membaca live chat YouTube resmi. Ikuti 4 langkah cepat ini:

1

Buka Google Cloud Console

Kunjungi console.cloud.google.com dan login dengan akun Google Anda.

2

Buat Project Baru

Klik menu project di bagian kiri atas, pilih New Project, beri nama misalnya "StreamAlerts", lalu klik Create.

3

Aktifkan "YouTube Data API v3"

Di kolom pencarian paling atas ketik YouTube Data API v3, klik hasil tersebut, lalu klik tombol biru ENABLE.

4

Buat Kredensial API Key

Buka tab Credentials di menu kiri, klik + CREATE CREDENTIALS → pilih API key. Salin kode API key (berawalan AIzaSy...) dan tempelkan ke dashboard StreamVox ini.
